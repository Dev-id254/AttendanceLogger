# UML Artefacts (placeholders)

During the design phase the following UML 2.x diagrams will be produced to satisfy academic requirements:

- **Use Case Diagram** – actors (lecturer, student, ESP32) and primary use cases (scan attendance, view dashboard, manage students).
- **Class Diagram** – classes representing Students, Courses, Attendance, Device, Lecturer, with associations.
- **Sequence Diagrams** – show interaction for events like "ESP32 publishes attendance via MQTT" and "User fetches attendance via UI".
- **ERD (Entity-Relationship Diagram)** – normalized database schema in 3NF as defined in `Database/schema.sql`.

Tools such as Draw.io, Lucidchart or StarUML can be used to draw the actual diagrams. Images can be placed into this folder later.
